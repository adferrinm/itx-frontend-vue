# Mobile Store

A single-page application for browsing and purchasing mobile devices.

## Getting Started

### Prerequisites

- Node.js >= 20
- npm >= 10

### Install

```bash
npm install
```

### Run

```bash
npm start        # development server
npm run build    # production build
npm run test     # run tests
npm run lint     # lint and format check
```

## Tech Stack

- Vue 3 + TypeScript
- Vite
- Vue Router 4
- Pinia
- Tailwind CSS
- Vitest
